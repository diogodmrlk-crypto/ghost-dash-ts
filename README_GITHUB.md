# Ghost Dash TypeScript 🚀

Um dashboard moderno para gerenciamento de chaves API, construído com **React 19**, **TypeScript** e **Tailwind CSS**.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fmanus-ai%2Fghost-dash-ts&project-name=ghost-dash&repository-name=ghost-dash-ts)

## ✨ Features

- ✅ **100% TypeScript** - Type-safe em toda a aplicação
- ✅ **React 19** - Últimas features e performance
- ✅ **Tailwind CSS 4** - Estilização moderna
- ✅ **Vite** - Build rápido e otimizado
- ✅ **Multilíngue** - Português, Inglês e Vietnamita
- ✅ **Pronto para Vercel** - Deploy em 1 clique

## 🚀 Deploy Rápido

### Opção 1: Clique no Botão (Mais Fácil)
Clique no botão "Deploy with Vercel" acima ☝️

### Opção 2: Via CLI
```bash
npm i -g vercel
vercel
```

### Opção 3: Manual
1. Clone este repositório
2. Instale: `npm install`
3. Build: `npm run build`
4. Deploy na Vercel

## 📁 Estrutura

```
client/src/
├── pages/       # Home, Keys, Devices, Packages, Profile
├── components/  # Componentes reutilizáveis
├── contexts/    # AppContext (estado global)
├── lib/         # Utilitários, i18n, constantes
└── types/       # TypeScript types
```

## 🎨 Personalizar

- **Cores**: Edite `client/src/index.css`
- **Idiomas**: Edite `client/src/lib/i18n.ts`
- **Layout**: Edite `client/src/pages/*.tsx`
